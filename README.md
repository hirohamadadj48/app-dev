# app-dev
First Repository

Welcome to the **Stranger Things Fan Tracker** repository! This is an application development project designed to provide real-time updates, character profiles, and episode guides for fans of the hit series.

---

* **Character Database:** Full profiles of Eleven, Mike, and the Hawkins gang.
* **Episode Guide:** Interactive logs for Seasons 1 through 4.
* **Trivia Quiz:** A built-in mini-game testing user knowledge.

---

1. **Frontend:** React Native / Flutter (Mobile UI)
2. **Backend:** Node.js with Express framework
3. **Database:** MongoDB for tracking user favorites
